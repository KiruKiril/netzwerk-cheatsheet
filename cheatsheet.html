L2 VLAN & Trunk Ports OSI Layer 2 ►

VLAN = Virtual LAN – logische Netzwerktrennung auf Layer 2. PCs in verschiedenen VLANs koennen NICHT direkt pingen (ohne Router).

Cisco Switch – VLAN konfigurieren

VLANs erstellen und benennen
enable configure terminal vlan <100> name <HR> vlan <200> name <PROD> exit
Access Port einem VLAN zuweisen
interface fastEthernet <0/1> switchport mode access switchport access vlan <100> exit
Trunk Port konfigurieren (zwischen Switches)
interface fastEthernet <0/24> switchport mode trunk exit
VLANs und Ports pruefen
show vlan brief show interfaces trunk
Port-TypFunktionVLAN-Tag
Access PortVerbindet Endgeraet (PC/Server)ohne Tag
Trunk PortVerbindet Switches/Routermit 802.1q Tag
ADV Inter-VLAN Routing – IEEE 802.1q (Router-on-a-Stick) OSI Layer 2 ►

Router-Subinterfaces leiten Verkehr zwischen VLANs weiter. Physischer Port zum Switch = Trunk.

Beispiel: VLAN 100 (HR) + VLAN 200 (PROD)

Physisches Interface aktivieren
interface gi0/0 no shutdown exit
Subinterface VLAN 100 (HR) konfigurieren
interface gi0/0.<100> encapsulation dot1q <100> ip address <192.168.1.1> <255.255.255.128> exit
Subinterface VLAN 200 (PROD) konfigurieren
interface gi0/0.<200> encapsulation dot1q <200> ip address <192.168.1.129> <255.255.255.128> exit
Route pruefen (von PC: zeigt Hop ueber Router)
tracert <ziel-ip> (Windows) traceroute <ziel-ip> (Linux/Cisco)
Switch → Router: Trunk konfigurieren! Verkehr: VLAN100 → Router Subinterface .100 → .200 → VLAN200
BASIC Spanning Tree Protocol (STP) OSI Layer 2 ►

STP (IEEE 802.1D): Verhindert Schleifen in geswitchten Netzwerken durch Blockieren redundanter Ports.

Port-Zustaende

ZustandBedeutung
Root FWDRoot-Switch Port, forwarding
DESG FWDDesignated Port, forwarding
ALTN BLKAlternativer Port, blockiert (verhindert Schleife)
LearningUebergangsphase (~15 Sek) vor Forwarding
STP-Status anzeigen
show spanning-tree
Port-Status + Speed/Duplex
show interfaces fa<0/1>
Bei Link-Ausfall: STP aktiviert blockierten ALTN-Port nach ~30 Sek. (Convergence)
⚠️ Speed/Duplex-Mismatch (z.B. PC: 10M HalfDuplex ↔ Switch: 100M FullDuplex) → kein Ping! Auto-Negotiation verwenden.
ADV Etherchannel (LACP – Link Aggregation) OSI Layer 2 ►

Etherchannel = mehrere physische Links → 1 logischer Link. Protokoll: LACP (IEEE 802.3ad). Gibt Redundanz + mehr Bandbreite.

Etherchannel konfigurieren (LACP)
interface range fa<0/1-2> channel-group <1> mode active exit interface port-channel <1> switchport mode trunk exit
Etherchannel Status pruefen
show etherchannel summary
LACP: active = sendet LACP-Pakete | passive = wartet. Mindestens eine Seite muss active sein.

BASIC Dynamisches Routing – RIP OSI Layer 3 ►

RIP = Routing Information Protocol (dynamisch, Distance-Vector). Max. 15 Hops, Konvergenz ~30 Sek.

RIP konfigurieren (Cisco)

✓ RIP: Bei Link-Ausfall → automatischer Failover ueber alternative Route!

ADV Dynamisches Routing – OSPF OSI Layer 3 ►

OSPF = Open Shortest Path First (Link-State, schnell, skalierbar). Area 0 = Backbone.

OSPF konfigurieren (Beispiel Router Fribourg)
router ospf 1 router-id <192.168.17.1> log-adjacency-changes network <192.168.17.1> 0.0.0.0 area 0 network <192.168.1.1> 0.0.0.0 area 0 network <192.168.1.10> 0.0.0.0 area 0 !

Routing-Tabelle (O = OSPF-Route)

ADV DHCP Relay (IP Helper) OSI Layer 4–7 ►

DHCP Relay: Router leitet DHCP-Broadcasts als Unicast an DHCP-Server weiter. Noetig wenn DHCP-Server und Clients in verschiedenen Subnetzen/Standorten sind.

IP Helper auf Cisco Router konfigurieren
interface <fastEthernet 0/0> ip helper-address <dhcp-server-ip> exit
Ablauf: PC → DHCP Broadcast → Router (ip helper) → Unicast → DHCP-Server → Router → PC

LAB 1: Layer-3-Switch mit SVI (Switch Virtual Interface)

PC0 (VLAN10, 192.168.10.11/24, GW .1) ↔ PC1 (VLAN20, 192.168.20.11/24, GW .1) ueber Layer-3-Switch

Layer-3-Switch: VLANs + Routing + SVI konfigurieren
! VLANs erstellen vlan 10 vlan 20 ! IP-Routing aktivieren (Layer 3!) ip routing ! SVI fuer VLAN 10 interface vlan 10 ip address 192.168.10.1 255.255.255.0 no shutdown exit ! SVI fuer VLAN 20 interface vlan 20 ip address 192.168.20.1 255.255.255.0 no shutdown exit ! Access Ports zuweisen interface fa0/1 switchport mode access switchport access vlan 10 exit interface fa0/2 switchport mode access switchport access vlan 20 exit

LAB 2: Router-on-a-Stick (Subinterfaces auf Router)

PC0 (VLAN10) ↔ PC1 (VLAN20) ueber Router. Switch hat Trunk auf fa0/24 zum Router.

Router: Physisches Interface + Subinterfaces konfigurieren
! Physisches Interface aktivieren interface GigabitEthernet0/0/0 no shutdown exit ! Subinterface VLAN 10 interface GigabitEthernet0/0/0.10 encapsulation dot1Q 10 ip address 192.168.10.1 255.255.255.0 exit ! Subinterface VLAN 20 interface GigabitEthernet0/0/0.20 encapsulation dot1Q 20 ip address 192.168.20.1 255.255.255.0 exit
Switch: Trunk Port zum Router konfigurieren
interface fa0/24 switchport mode trunk exit
Verifikation: Ping + Routing-Tabelle
ping 192.168.20.11 (von PC0 auf PC1) show ip route (auf Router) show vlan brief (auf Switch)
